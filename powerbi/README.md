# Power BI Dashboard Starter Kit

This folder provides a practical blueprint for building a Power BI dashboard
on top of the Databricks gold and silver outputs generated by this project.
It is intentionally source-controlled as documentation and reusable assets so
that the dashboard can be rebuilt without checking a binary `.pbix` file into
Git.

## Recommended Connection Pattern
Use the Databricks SQL Warehouse connector from Power BI Desktop and import the
following Delta-backed tables.

### Gold tables for dashboard visuals
- `claim_rate_by_region`
- `claim_rate_by_segment`
- `claim_rate_by_fuel_type`
- `claim_rate_by_vehicle_age_band`
- `claim_rate_by_customer_age_band`
- `claim_rate_by_ncap_rating`
- `portfolio_summary`

### Silver table for drill-through and slicers
- `insurance_policy_data_clean`

The gold tables keep the main report fast and simple, while the silver table
supports detailed drill-through pages and ad-hoc slicing by multiple policy
attributes.

## Suggested Semantic Model
Keep a lightweight star-style model in Power BI:

- `Policy Detail` (silver) as the detailed fact table.
- `Portfolio Summary` as a disconnected KPI summary table.
- Gold aggregate tables as visual-specific helper tables.
- Optional hand-authored dimension tables for sort order:
  - `DimCustomerAgeBand`
  - `DimVehicleAgeBand`
  - `DimNCAPRating`
- `Safety Feature Selector` from `safety_feature_selector.csv` for reusable
  feature-comparison visuals

If you prefer to minimise model size, you can also use only the silver table
plus DAX measures. For this repository, the hybrid approach is recommended
because it aligns with the existing medallion outputs and keeps report refresh
logic easy to explain.

## Dashboard Pages

### 1. Executive Overview
Primary goal: give an insurance portfolio manager an at-a-glance risk summary.

**Cards / KPIs**
- Total policies
- Total claims
- Overall claim rate
- Average subscription length
- Average customer age

**Visuals**
- Clustered bar chart: claim rate by region
- Column chart: claim rate by segment
- Donut chart: policies by fuel type
- Matrix: region × segment with conditional formatting on claim rate

**Slicers**
- Region code
- Segment
- Fuel type
- NCAP rating

### 2. Customer and Vehicle Risk Drivers
Primary goal: explain how claim outcomes vary with driver age, vehicle age,
and safety profile.

**Visuals**
- Bar chart: claim rate by customer age band
- Bar chart: claim rate by vehicle age band
- Line chart: claim rate by NCAP rating
- Scatter plot: region density vs claim rate (from silver table)
- Ribbon chart: claim rate by fuel type within segment

**Slicers**
- Customer age band
- Vehicle age band
- Transmission type
- Engine type

### 3. Safety Feature Impact
Primary goal: compare claim performance for policies with and without major
safety features.

**Visuals**
- Clustered column chart: claim rate by `has_feature` for each feature
- Heat map / matrix: feature adoption by segment
- Decomposition tree: claim status by safety feature → segment → fuel type

Recommended starting features:
- ESC
- Brake assist
- Parking sensors
- TPMS
- Parking camera

### 4. Policy Drill-Through
Primary goal: allow analysts to investigate the policies behind any high-risk
aggregate.

**Visuals**
- Detailed table from the silver layer
- Histogram of subscription length
- Table of policy attributes including region, segment, fuel type, customer
  age, vehicle age, NCAP rating, and safety features

Add drill-through filters on:
- region_code
- segment
- fuel_type
- customer_age_band
- vehicle_age_band

## Core Measures
Import the measures from `insurance_risk_dashboard_measures.dax` into the Power
BI model. These measures assume the detailed silver table is loaded as
`Policy Detail`.

## Custom Theme
Apply `auto_insurance_dashboard_theme.json` from Power BI Desktop using:

`View` → `Themes` → `Browse for themes`

The theme uses a restrained insurance-style palette:
- dark navy for primary risk metrics
- teal for neutral portfolio distributions
- amber for attention states
- red for elevated claim-rate cues

## Visual Design Guidance
- Use **claim rate** as the primary colour-encoded metric.
- Sort age bands with custom sort columns rather than alphabetically.
- Use conditional formatting thresholds such as:
  - green: < portfolio claim rate
  - amber: within 10% of portfolio claim rate
  - red: > 10% above portfolio claim rate
- Show both `claim_rate` and `total_policies` together so small sample sizes do
  not mislead consumers.
- Add report-page tooltips with `total_claims`, `total_policies`, and
  `avg_subscription_length`.

## Build Steps in Power BI Desktop
1. Connect to Databricks SQL Warehouse.
2. Load the gold tables and the silver clean table.
3. Rename the silver table to `Policy Detail`.
4. Load `safety_feature_selector.csv` as `Safety Feature Selector`.
5. Create the measures from `insurance_risk_dashboard_measures.dax`.
6. Apply the custom theme JSON.
7. Create optional sort tables for ordered age bands.
8. Assemble the four report pages described above.
9. Publish to the Power BI Service and configure a refresh schedule aligned to
   the Databricks pipeline cadence.

## Recommended Refresh Strategy
Because the pipeline writes curated Delta outputs, the cleanest production setup
is:
- Databricks pipeline refresh completes first.
- Power BI semantic model refresh runs afterwards.
- Dashboard alerts monitor unusually high claim-rate changes by region or
  segment.
